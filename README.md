# What are Scalpers?
If you're living under a rock, Scalpers are people who spend all there money to buy items that are popular to then sell them on the internet for 3 times the price.

# Why does it piss me off?
It pisses me off because I work at Target and every time there's a item in high demand, there's always a scalper there trying to buy as much as they can. The store tries to stop them by limiting them to only 2 per person, as well as putting them behind service desk. 
Unfortunately, this doesn't stop there never ending greed and they will always try to find a way to get more then the limit. most of the time its trying to act like they are buying 2 for the first time today, and because there is no way to really check,
they sometimes get away with 2-5 times the limit. So, if the only real outcome is that the people at service desk have to suffer while scalpers still get away with more then they should, why not make them suffer too.

# what did I make in a fit of rage to combat them
To fight these degenerates, Ive made a basic python project for facial recognition.
the program takes a photo from the camera and sees if there is a face in frame. If it finds a face then it turns that face into math (a face print) before checking to see if the face matches any in the database.
If it does recognize the face then it notifies that the guest has already been here for the day. Otherwise, if the face does not match any then it says that they're "good to go" and then stamps the time before adding them to the database.
every time the program starts it runs a function that checks the database for any faces with a timestamp older then the current day, if there is any then they are quickly deleted so guests can buy again the next day without being told that they have already been there
